# Симуляция баланса

`balance_sim.sql` берёт настоящие функции тика из базы и прогоняет их на «часах симуляции».
Запускать только на локальной копии базы (все миграции применены):

```sql
\i supabase/sim/balance_sim.sql
select * from sim_run(3, 5);   -- 3 игрока в городе, 5 дней
```

Сценарий: у каждого игрока все бизнесы, заходит 2 раза в день (9:00 и 21:00 по Москве),
забирает выручку, ставит цену как на рынке, пополняет склады до полного; пекарня снабжает свой магазин
(считаем по цене поставщика), остаток — оптовику; маркетплейс докупает кофе и хлеб по оптовой цене;
агентство сдаёт кампании оптовику; бригада — только городские заказы.
