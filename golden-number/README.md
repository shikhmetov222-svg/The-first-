# Золотой номер

Telegram Mini App: крутишь барабаны и получаешь красивые телефонные номера шести стран. Номер можно продать или оставить в коллекции, а коллекция приносит доход в кассу.

## Что где лежит

| Папка | Что внутри |
|---|---|
| `supabase/functions/_shared/game/config.ts` | **Весь конфиг игры**: страны, операторы, префиксы с источниками, курсы, тиры, T9-словарь, калибровка экономики |
| `supabase/functions/_shared/game/logic.ts` | Правила: генерация номера, `evaluate()`, цены, касса, опыт. Используется только на сервере (клиенту — для подписей) |
| `supabase/functions/_shared/telegram.ts` | Проверка подписи Telegram initData |
| `supabase/functions/golden-number/index.ts` | Edge Function `golden-number`: проверяет подпись, генерирует номер, вызывает SQL |
| `supabase/migrations/0001_golden_number.sql` | Таблицы, RLS, атомарные денежные операции |
| `supabase/tests/money_test.sql` | Проверка денежных операций на настоящем Postgres |
| `app/` | Фронтенд (Vite + TypeScript) |
| `app/tests/` | Тесты правил редкости, экономики и подписи Telegram |
| `app/scripts/simulate.ts` | Симуляция экономики |

## Версия 3: друзья, достижения, рынок

- **Друзья.** Ссылка `t.me/simmmcardd_bot?startapp=r<telegram id>`. Новый игрок по ссылке получает 10 подарочных прокруток. Пригласивший получает 5 000 ₽ и 3 прокрутки, когда друг сделает 30 прокруток (защита от накрутки ботами).
- **Достижения и коллекции регионов** (`ACHIEVEMENTS` в `config.ts`). Прогресс считается по истории прокруток на сервере (`gn_stats`), награду выдаёт только сервер, и повторно её не получить.
- **Рынок.** Номер из коллекции выставляется за 50–500% оценки. Комиссия 5% сгорает. Не больше 5 лотов у игрока и 3 покупок у одного продавца в сутки. Купленный номер приносит доход по оценке, а не по цене покупки, поэтому перепродажа не раздувает кассу.
- **Интерфейс.** 5 вкладок, шкала редкости над номером, «Почему такая цена», «Похвастаться», действия по нажатию на номер, экран «Ещё».
- **Скриншоты:** `docs/screens/v3/`.
- **Не делали:** казино, дуэли на деньги, розыгрыши (риск блокировки бота и проблем с законом). Магазин за Telegram Stars — отдельный этап: нужен приём платежей ботом и правила возврата.

## Безопасность

- Номер генерирует и оценивает **только сервер** (криптостойкий генератор). Клиент лишь показывает анимацию до уже известного результата.
- Ставка, продажа, касса, опыт и уровень меняются в SQL-функциях. Каждая работает в одной транзакции и блокирует строку игрока, поэтому двойные нажатия и параллельные запросы не создают денег.
- RLS включён на всех таблицах без политик. Клиентские роли (`anon`, `authenticated`) не могут ни читать таблицы, ни вызывать функции. Это проверяет `money_test.sql`.
- Каждый запрос проверяет подпись `initData` токеном бота. Подпись старше суток не принимается.
- Номера нигде не кликабельны: нет `tel:`-ссылок, отключено автоопределение телефонов, текст нельзя выделить или скопировать. Делиться можно только картинкой. Операторы показаны только названием, без логотипов и фирменных цветов.

## Экономика

- Прокрутка: `1000 ₽ × множитель страны × ставка` (×1, ×2, ×5, ×10).
- Цена номера: `ставка × (0,75 + 0,17 × (множитель редкости − 1))` — обычный 75% ставки, Редкий ×12 ≈ 2,6 ставки, Эпический ×40 ≈ 7,4, Легендарный ×500 ≈ 85.
- Узорных номеров 6,6%. Код из одинаковых цифр (777, 999, 44…) выпадает с шансом 2% в любой стране. Из этого получается средняя отдача ≈ 90% ставки.
- Касса: 3% цены номера в час, копится максимум 8 часов.
- Опыт за прокрутку: `10 + min(90, round(log10(множитель) × 25))`. На следующий уровень нужно `уровень × 100`.
- Если игрок разорился и продавать нечего, можно получить 5 000 ₽, но не чаще раза в 4 часа.

## Секреты — только в переменных окружения

| Что | Куда | Секрет? |
|---|---|---|
| `GN_TELEGRAM_BOT_TOKEN` | Supabase → Edge Functions → Secrets | **Да.** Никуда больше не вставлять |
| `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY` | Supabase подставляет в функцию сам | **Да.** Ничего делать не нужно |
| `VITE_API_URL` | Netlify → Environment variables | Нет, это просто адрес |

Файлы `.env*` в git не попадают (см. `app/.gitignore`).

## Деплой с нуля по шагам

### 1. Supabase (база и сервер)
1. Зайди на supabase.com → **New project**. Имя `golden-number`, регион **Central EU (Frankfurt)**. Пароль базы сохрани в менеджере паролей.
2. Слева **SQL Editor** → **New query**. Вставь весь файл `supabase/migrations/0001_golden_number.sql` → **Run**. Должно появиться «Success».
3. Залей Edge Function `api`. Это делается одним из двух способов:
   - проще всего попросить меня: Supabase подключён к нашему чату, и я залью функцию сам;
   - или на своём компьютере: `npx supabase login`, затем `npx supabase link --project-ref <ID проекта>`, затем `npx supabase functions deploy golden-number --no-verify-jwt` (запускать из папки `golden-number`).
4. **Edge Functions → golden-number → Details**: выключатель **Enforce JWT verification** должен быть **выключен**. Вход у нас через подпись Telegram, а не через Supabase Auth.
5. Адрес функции выглядит как `https://<ID проекта>.supabase.co/functions/v1/golden-number`. Он понадобится для Netlify.

### 2. @BotFather (бот)
1. В Telegram открой @BotFather → `/newbot` → придумай имя и username (должен заканчиваться на `bot`).
2. BotFather пришлёт токен. **Не отправляй его никому, в том числе мне.** Сразу открой Supabase → **Edge Functions → Secrets** → **Add new secret**: имя `GN_TELEGRAM_BOT_TOKEN`, значение — токен → **Save**.

### 3. Netlify (сайт)
1. app.netlify.com → **Add new site → Import an existing project → GitHub** → выбери репозиторий и ветку `claude/golden-number` (после слияния — `main`).
2. **Base directory**: `golden-number/app`. Остальное Netlify возьмёт из `golden-number/app/netlify.toml`.
3. **Add environment variables** → `VITE_API_URL` = адрес функции из шага 1.5 → **Deploy**.
4. Когда сайт соберётся, скопируй его адрес (вида `https://что-то.netlify.app`).

### 4. Подключить сайт к боту
1. @BotFather → `/mybots` → твой бот → **Bot Settings → Configure Mini App → Enable Mini App** → вставь адрес Netlify.
2. Там же: **Bot Settings → Menu Button** → адрес Netlify, текст кнопки «Играть».
3. Открой своего бота, нажми «Играть». Должен появиться баланс 10 000 ₽.

## Для разработчика

```bash
cd golden-number/app
npm install
npm run dev          # http://localhost:5173/?mock — игра без сервера (только в dev)
npm test             # правила редкости, экономика, подпись Telegram
npm run sim          # симуляция: 300 000 прокруток на каждую страну
npm run build        # проверка типов + сборка
# денежные операции на любом Postgres:
psql "<строка подключения>" -f ../supabase/migrations/0001_golden_number.sql -f ../supabase/tests/money_test.sql
```
