# CAPITAL

Многопользовательский бизнес-симулятор в Telegram Mini App.

- `app/` — фронтенд (React + Vite + TypeScript), хостинг Netlify, собирается автоматически из ветки `main`.
- `supabase/migrations/` — база Postgres: таблицы и вся игровая логика (SQL-функции).
- `supabase/functions/api/` — Edge Function: проверяет подпись Telegram и вызывает SQL-функции.

Вся игровая логика и деньги — только на сервере. Клиент отправляет действия и показывает результат.

## Как устроена игра

- **Вход**: initData от Telegram, подпись проверяется на сервере при каждом запросе.
- **Бизнесы**: кофейня, магазин, пекарня (печёт хлеб из муки и бесплатно снабжает свой магазин). Склады ограничены.
- **Тик** каждые 5 минут (`pg_cron` → `tick()`): производство, продажи, выручка копится в кассах.
- **Рынок**: на кофе и хлеб. Спрос зависит от времени суток (Москва), покупатели выбирают продавца по цене.
  Больше продавцов — ниже рыночная цена.
- **Боты**: «Демпингер», «Премиум», «Осторожный». Уходят по одному, когда живых игроков становится больше. В рейтинг не входят.
- **Решение дня**: одна карточка-событие в сутки, последствия (эффекты, деньги, мука) считает сервер.
- **Сезон** 7 дней, заканчивается в 21:00 по Москве. Рейтинги: по капиталу и по росту за 24 часа.
  В конце сезона итоги сохраняются, все начинают заново со 100 000 ₽ (`hourly()` раз в час).
- **Капитал** = деньги + выручка в кассах + товар по закупочной цене + 70% стоимости бизнесов.

Все суммы в базе хранятся в копейках.

## Локальный запуск фронтенда
