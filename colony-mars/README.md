# Колония на Марсе

Игра для Telegram (Mini App). Ты командуешь колонией на Марсе, и ей нужно продержаться 8 раундов.

Сейчас это **этап 1**: одиночная игра. Сервер не нужен, всё работает прямо в браузере.

## Правила

- Ресурсы на старте: кислород 10, вода 10, еда 10, энергия 10, запчасти 4.
- Каждый раунд колония сама тратит 1 кислород, 1 воду и 1 еду.
- Каждый раунд происходит одно случайное событие:
  - буря пыли: −2 энергии;
  - утечка: −3 воды;
  - эпидемия: −1 еды;
  - находка: +2 запчасти;
  - метеорит: −2 кислорода.
- Действие «Починить энергосистему»: −1 запчасть, +3 энергии. Можно сделать один раз за раунд.
- Поражение: кончился кислород, вода или еда (стало 0).
- Победа: колония прожила 8 раундов.

## Как открыть в браузере

1. Скачай папку `colony-mars` на компьютер.
2. Дважды щёлкни по файлу `index.html`. Игра откроется в браузере.

В браузере нет Telegram, поэтому игрок называется «Колонист». Всё остальное работает так же, как в Telegram.

## Как выложить в интернет (Netlify Drop)

1. Открой https://app.netlify.com/drop и войди в Netlify.
2. Перетащи папку `colony-mars` целиком в окно браузера.
3. Через несколько секунд Netlify покажет адрес вида `https://что-то.netlify.app`. Скопируй его: он нужен для бота.

Чтобы обновить игру, перетащи папку ещё раз на странице своего сайта в Netlify, во вкладке **Deploys**.

## Ручные шаги: подключить игру к боту

Это делаешь ты сам, в Telegram:

1. Найди в Telegram бота **@BotFather** и нажми «Старт».
2. Отправь `/newbot`.
   - Придумай название, например «Колония на Марсе».
   - Придумай имя бота: латиницей, в конце `bot`, например `mars_colony_game_bot`.
   - BotFather пришлёт токен. Никому его не показывай. На этапе 1 он не нужен, но сохрани его на будущее.
3. Подключи игру к боту. Подойдёт любой из двух способов:
   - **Кнопка меню** (проще): отправь `/setmenubutton`, выбери своего бота, пришли адрес из Netlify и название кнопки, например «Играть».
   - **Отдельное приложение**: отправь `/newapp`, выбери бота и ответь на вопросы: название, описание, картинка 640×360, адрес из Netlify и короткое имя. Тогда игра откроется по ссылке `t.me/имя_бота/короткое_имя`.
4. Открой своего бота и нажми кнопку «Играть».

### Ручные шаги: подключить Supabase

Делай по одному шагу. Если что-то не получилось, напиши мне, на каком шаге остановился.

1. **Освободить место (если нужно).** На бесплатном тарифе можно держать 2 активных проекта. Если у тебя их уже два, поставь ненужный на паузу: проект → **Project Settings → General → Pause project**. Данные сохранятся.
2. **Создать проект.** На https://supabase.com нажми **New project**. Название: `colony-mars`. Регион: **Central EU (Frankfurt)**. Пароль базы придумай и сохрани у себя: в игру он не попадает. Подожди 1–2 минуты, пока проект создастся.
3. **Включить анонимный вход.** Слева **Authentication → Sign In / Providers**, найди **Anonymous Sign-Ins** и включи. Нажми **Save**. Без этого игроки не смогут войти.
4. **Загрузить таблицы и правила.**
   - Слева **SQL Editor → New query**.
   - Открой файл `supabase/schema.sql`, скопируй **весь** текст и вставь в окно.
   - Нажми **Run**. Внизу должно появиться **Success. No rows returned**.
   - Файл можно запускать повторно: ничего не сломается.
5. **Скопировать адрес и ключ.** Слева **Project Settings → API Keys** (или кнопка **Connect** вверху):
   - **Project URL** — вида `https://abcdefgh.supabase.co`;
   - **Publishable key** — начинается с `sb_publishable_…`. Если в проекте только старые ключи, возьми **anon public**.
6. **Вставить их в `config.js`.** Открой файл `config.js` и замени две заглушки:
   ```js
   window.COLONY_CONFIG = {
     supabaseUrl: 'YOUR_SUPABASE_URL',      // ← сюда Project URL
     supabaseKey: 'YOUR_PUBLISHABLE_KEY',   // ← сюда Publishable key
   };
   ```
   Оставь кавычки. **Секретные ключи** (`service_role`, `sb_secret_…`) сюда вставлять нельзя никогда. Публичный ключ безопасен: чужие данные он не открывает, это обеспечивают правила из `schema.sql`.
7. **Выложить игру заново** (Netlify Drop, как в разделе выше) или просто открыть `index.html` двумя окнами браузера для проверки.

### Как проверить командную игру

Нужно два «устройства». Подойдут телефон и компьютер, а на одном компьютере — обычное окно и окно «инкогнито» (у них раздельная память, поэтому это два разных игрока). Для старта нужно трое: добавь ещё одно окно другого браузера.

1. **Первое окно:** впиши имя (в Telegram оно подставится само), нажми **Создать игру**. Появится большой код из 6 цифр, «Игроки: 1 из 6», кнопка «Старт» серая.
2. **Второе окно:** нажми **Войти по коду**, введи код. Во втором окне должно быть «Игроки: 2 из 6», а в первом список **сам** дополнится, без перезагрузки.
3. **Третье окно:** войди так же. В первом окне кнопка **Старт** станет активной. В остальных окнах кнопки «Старт» нет, там написано «Ждём, пока хост начнёт игру».
4. **Старт:** нажми **Старт** в первом окне. У всех трёх появится «Игра началась!».
5. **Возврат:** в любом окне закрой вкладку (или приложение в Telegram) и открой игру снова. Ты сразу попадёшь в свою колонию. Кнопка «← В меню» из колонии не выводит: в меню появится «Вернуться в колонию».
6. **Ошибки:** введи неверный код: появится «Колония с таким кодом не найдена». Попробуй войти в уже начатую игру: «Эта игра уже началась».

Что значит сообщение на экране:

| Сообщение | Что делать |
|---|---|
| «Командная игра пока не настроена» | Вставь адрес и ключ в `config.js` (шаг 6) |
| «Не удалось войти в командную игру…» | Проверь, что включён **Anonymous Sign-Ins** (шаг 3) |
| «Could not find the function …» или «permission denied» | Выполни `supabase/schema.sql` ещё раз (шаг 4) |
| «○ Связи нет: список может не обновляться» | Realtime не работает: в Supabase **Database → Publications → supabase_realtime** должны быть таблицы `rooms` и `players`; запусти `schema.sql` ещё раз |

### Что важно знать

- **Комнаты живут сутки.** Старые удаляются сами, когда кто-то создаёт новую комнату.
- **Возврат по `telegram_id`.** Если телефон забыл вход, игрока узнают по его Telegram-id. Пока сервер не проверяет подпись Telegram (`initData`), поэтому Telegram-id можно подделать. Для игры с друзьями это не страшно, а проверку подписи добавим позже (вопрос 9 в `PLAN.md`).
- **Telegram-id не виден другим игрокам.** Он лежит в отдельной таблице, которую из браузера прочитать нельзя.

## Технические решения (кратко)

- **Без фреймворков и сборщика.** Чистые HTML, CSS и JS: файлы можно открыть или выложить как есть, ничего не устанавливая.
- **Одно состояние, один `render()`.** Все данные игры лежат в объекте `game`. После каждого действия экран целиком перерисовывается через `innerHTML`. Такой код проще читать: что лежит в `game`, то и видно на экране.
- **Один обработчик кликов на весь экран.** У кнопок есть атрибут `data-action`, и обработчик смотрит, какая нажата. После перерисовки его не нужно вешать заново.
- **Работает без Telegram.** Если `window.Telegram.WebApp` нет, переменная `tg` равна `null`. Тогда `tg.ready()` и `tg.expand()` не вызываются, а имя заменяется на «Колонист».
- **Защита имени.** Имя из Telegram перед выводом на экран превращается в обычный текст (`escapeHtml`). Иначе имя вроде `<img ...>` могло бы вставить в страницу чужой код.
- **Ресурсы не уходят в минус.** Если ресурс опускается ниже нуля, на экране будет 0. Поражение наступает при 0 кислорода, воды или еды.
- **Порядок раунда:** сначала по желанию делаешь действие, потом нажимаешь «Следующий раунд». Тогда колония тратит ресурсы и происходит событие. Если после 8-го раунда колония жива — победа.
- **Все числа вверху `app.js`** (`START_RESOURCES`, `ROUND_COST`, `EVENTS`, `TOTAL_ROUNDS`). Чтобы поменять баланс, достаточно поправить там.

Шаг 1 (комнаты и лобби) готов, см. выше. Подробный план — в `PLAN.md`. Осталось:
